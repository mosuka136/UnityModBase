UnityModBase is an infrastructure solution for Unity mod development. The repository contains the core library and a BepInEx lifecycle adapter, primarily providing shared lifecycle, configuration, logging, hotkey, translation, and IMGUI tooling for mods.

## Usage guide

### Using the bundled BepInEx launcher

1. Build or obtain `UnityModBase.dll` and `UnityModBase.BepInExLauncher.dll`.
2. Place both files in the target game's `BepInEx/plugins` directory.
3. Reference `UnityModBase.dll` from the mod project.
4. Follow the [core-library quick start](./UnityModBase/README_EN.md) to register the mod user, configuration, logging, and live controls.

The bundled launcher calls the framework's `Initialize`, `GameBootRegistry.Boot`, and `Dispose` entry points. Mods using this launcher must not drive the global lifecycle a second time.

### Using a custom host

Without the BepInEx launcher, the host must select safe Unity lifecycle points and call initialization, game-boot dispatch, and disposal in order. See the [core-library overview](./UnityModBase/README_EN.md) and [lifecycle API](./UnityModBase/API_EN.md) for the exact order and main-thread constraints.
